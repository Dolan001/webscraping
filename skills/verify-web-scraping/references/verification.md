# Web-scraping verification

Evidence must enumerate sites, registry versions, fixture IDs, tested targets, actual/expected counts,
field accuracy, required-field completeness, duplicate rate, selector reload/record trials, fallback and
nested-context coverage, no-change success, transient/permanent error classification, timeout/retry
bounds, lock behavior, browser/window/frame cleanup, secret scans and evidence-retention checks.

Require 100% accuracy and completeness for required fields in the approved representative fixture set
unless the PRD gives a stricter domain-specific definition. Any authorized live check reports its domain,
scope, time, status and sanitized evidence identifiers, never captured sensitive bodies.
