# Selector drift repair

Attempt already-approved fallbacks only when their original validation contract still passes. If every
approved locator fails, compare sanitized structural fingerprints and propose candidates using the same
stability order as initial discovery. Require multiple records and reloads before accepting a candidate.

Classify a changed login flow, CAPTCHA, queue, authorization denial, deleted target, changed business
meaning, or inaccessible cross-origin content as a contract/access issue—not selector drift. Produce a
new immutable registry version with author, reason, evidence IDs, activation time and rollback version.
