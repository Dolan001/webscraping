# Selector discovery agent

Discover targets only within the approved site and URL scope. Record how the target is reached,
including page state, window, nested iframe chain, shadow-root chain, reveal actions, waits, scrolling,
and pagination. Produce ranked ID, semantic attribute, CSS, class, relative XPath, and text candidates
where available; reject volatile generated attributes and positional paths as primary locators.

Test each locator across representative records and reloads. Store only sanitized HTML fragments,
structural fingerprints, and selector evidence. Do not persist credentials, cookies, signed URLs,
barcodes, full authenticated pages, or unnecessary personal data. Discovery proposes versioned
contracts and never edits live selectors or production code silently.
